1.) What were the four commands you used to assemble, compile, link, and run in the "Compiling and Assembling" section?

The four commands were:
//to create array_sum.o
gcc -c -march=haswell array_sum.S -o array_sum.o

//to create array_sum_speed.o
gcc -Wall -Wpedantic -std=c17 -march=haswell -c array_sum_speed.c -o array_sum_speed.o

//to combine array_sum.o and array_sum_speed.o into array_sum_speed
gcc array_sum_speed.o array_sum.o -o array_sum_speed

//to run array_sum_speed
./array_sum_speed 1000000

Assembly: 0.524 ms
C without -O3: 1.806 ms

After adding -O3, the C implementation took approximately 0.122 ms on average, while the assembly implementation took approximately 0.524 ms.
